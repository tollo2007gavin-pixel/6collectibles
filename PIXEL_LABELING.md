# Improve whitening detection with your boxes

1. In **Actions → Test pixel whitening candidates**, choose **edge_classifier** and run a fresh batch. Download the results, extract them, and open `candidate_review/review.html`.
2. Open **Draw whitening boxes** on each card and inspect all four corners. Click a blue box when it shows real whitening. Drag one green rectangle around each missed chip. A snug box around the chip is enough. Leave dust and glare alone. For a reviewed card with no chips, type **No whitening** in its notes. To skip a card, leave it entirely blank. Use **Uncertain** for individual spots you cannot judge.
3. Click **Download boxes for GitHub**. Upload that file to [the boxes upload page](https://github.com/tollo2007gavin-pixel/6collectibles/upload/main/review_labels) and commit it to **main**. Keep the filename and leave the file compressed. For a correction, use the same repository filename as the first upload. Remove a download suffix such as (1) if your browser added one. **Save marked review with photos** gives you an editable copy to keep on your computer.
4. Open **Actions → Improve pixel whitening from boxes**, select the run for your upload, and read its summary. It compares the current and proposed settings on the same reserved cards and reports chips found and false alarms. If it recommends keeping the current settings or collecting more boxes, use a fresh batch next time.
5. If a comparison qualifies and you want to use its settings, open **Actions → Use validated pixel settings** and enter the comparison run ID (the number at the end of that comparison’s GitHub URL). Future pixel whitening inspections use the approved settings.

Fresh reviews automatically reserve about 30% of physical-card groups before you make a mark. Review all cards the same way. On older reviews, click **Reserve about 30%** before starting. If you recognize two photos as the same physical card, use **Card grouping options** before marking so both belong to the same group and split. An entirely blank card contributes no judgments. Any card with a mark or note contributes its untouched candidate boxes as examples of spots that should not be flagged.

The comparison uses saved pixel measurements. Draw missed chips even when there is no blue box: these marks show where candidate detection needs work. If a report exposes your reserved cards, use fresh cards for the next independent check.
