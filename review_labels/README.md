# Upload reviewed boxes here

Choose **Download boxes for GitHub** in the card review. Upload the resulting `pixel-whitening-labels…json.gz` or `.json` here on **main** using **Add file → Upload files**. Keep the batch filename and leave compressed files as they are. Uploading starts **Improve pixel whitening from boxes** in Actions.

If you downloaded an HTML file with photos, open it on your computer and click **Download boxes for GitHub** to export the saved boxes.
